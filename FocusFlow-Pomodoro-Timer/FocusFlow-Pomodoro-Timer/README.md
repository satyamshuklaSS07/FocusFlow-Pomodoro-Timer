# FocusFlow — Pomodoro Timer

A responsive Pomodoro timer built with HTML, CSS, and vanilla JavaScript.

## Features
- Focus, short-break, and long-break modes
- Start, pause, reset, and skip controls
- Configurable durations and long-break cycle
- Circular countdown progress indicator
- Session count, focus-time stats, and daily goal progress
- Optional sound alerts and browser notifications
- Saves timer preferences in local storage
- Keyboard shortcut: `Space` to start/pause; `Esc` to close settings

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

No build tools or dependencies required. Google Fonts are loaded online; system fonts are used as fallback.
